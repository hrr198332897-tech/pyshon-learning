# 项目阶梯

项目从“能运行”逐步发展到“能展示”。不要等到课程全部完成才开始。

## 项目 1: 命令行小工具

当前参考实现: [学习记录命令行工具](01-study-tracker/README.md)

建议方向:

- 记账记录器
- 单词复习器
- 每日计划工具

必须包含: 输入、处理、文件保存、错误提示、README。

## 项目 2: 数据自动化

当前参考实现: [学习数据报告生成器](02-study-report/README.md)

建议方向:

- 公开 API 数据收集与分析
- CSV 数据清洗报告
- 本地文件整理器

必须包含: 真实数据、自动处理、结构化输出、至少一个测试。

## 项目 3: AI 应用

当前参考实现: [本地知识搜索](03-knowledge-search/README.md)

建议方向:

- 个人知识库问答
- 文档总结工具
- 带引用来源的检索助手

必须包含: 环境变量管理、AI 调用、错误处理、使用说明、效果验证。

每个项目建立独立目录，并从头到尾记录问题和决策。
