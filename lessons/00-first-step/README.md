# 第 0 课: 第一行 Python

这一课不用理解函数，不用写复杂代码。你只需要认识一个“盒子”和一个“显示命令”。

## 1. 变量像一个盒子

```python
message = "你好"
```

这句话的意思是：

- `message` 是盒子的名字。
- `=` 表示把右边的内容放进盒子里。
- `"你好"` 是要保存的文字。

## 2. print 表示显示

```python
print(message)
```

`print` 的意思是：把盒子里的内容显示出来。

## 3. 完整程序

```python
message = "你好，我正在学习 Python"
print(message)
```

运行结果:

```text
你好，我正在学习 Python
```
