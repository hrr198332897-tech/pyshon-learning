# 第 10 课: RAG 文档切分与上下文

预计时间: 150 到 210 分钟

## 本课目标

- 理解长文档为什么要切分成块。
- 使用固定长度和重叠窗口切分文本。
- 清理空白或无意义块。
- 为每段上下文保留来源编号。
- 构造约束明确的回答提示。

## 为什么切分

如果整本书只生成一个向量，检索结果会非常模糊。把文档切成较小片段后，每段内容更集中，更容易和问题匹配。

重叠窗口可以避免答案刚好落在切口处时丢失上下文:

```python
step = max_chars - overlap
```

## 上下文编号

检索后的片段需要保留来源:

```text
[1] Python 函数用于复用逻辑。
[2] 变量用于保存值。
```

模型回答时可以引用 `[1]`、`[2]`，用户也能核对原文。

## 提示约束

一个可靠的 RAG 提示至少应说明:

- 只根据提供的上下文回答。
- 上下文不足时明确说不知道。
- 不能编造来源。
- 回答后列出使用到的来源编号。
