# 课程目录

课程按从易到难的顺序组织。每课都包含讲解、示范、练习和验收方式。

## 已完成课程

- `01-variables-and-flow/`: 变量、数据类型、输入输出、函数和 f-string。
- `02-conditions-and-loops/`: 布尔判断、if/elif/else、for 循环和枚举。
- `03-lists-dicts-functions/`: 列表、字典、排序和函数组合。
- `04-files-and-errors/`: 路径、JSON 文件、异常处理和本地数据保存。
- `05-csv-data/`: CSV 读取、字段转换、数据校验和结果写回。
- `06-http-json/`: HTTP 请求、JSON 响应、错误处理和本地测试服务器。
- `07-pandas-basics/`: DataFrame、筛选、分组汇总和结果导出。
- `08-scikit-learn/`: 数据集划分、Pipeline、训练、预测和准确率评估。
- `09-tfidf-retrieval/`: TF-IDF 向量化、余弦相似度和文档检索。
- `10-rag-context/`: 文档切分、重叠窗口、上下文编号和提示构造。

## 使用方法

1. 先阅读课程说明，并运行示范代码。
2. 自己动手完成对应练习。
3. 运行该练习目录中的测试。
4. 把结果和问题写进当周学习记录。

也可以用仓库统一检查命令一次运行全部测试:

```powershell
python tools/run_checks.py
```

遇到错误时，先保留完整错误信息，再尝试自己解释问题。AI 更适合帮助你定位和解释，而不是直接跳过练习过程。
