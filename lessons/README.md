# 课程目录

课程按从易到难的顺序组织。每课都包含讲解、示范、练习和验收方式。

## 已完成课程

- `01-variables-and-flow/`: 变量、数据类型、输入输出、函数和 f-string。

## 使用方法

1. 先阅读课程说明，并运行示范代码。
2. 自己动手完成对应练习。
3. 运行该练习目录中的测试。
4. 把结果和问题写进当周学习记录。

也可以用仓库统一检查命令一次运行全部测试:

```powershell
python tools/run_checks.py
```

遇到错误时，先保留完整错误信息，再尝试自己解释问题。AI 更适合帮助你定位和解释，而不是直接跳过练习过程。
