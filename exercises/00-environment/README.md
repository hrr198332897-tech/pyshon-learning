# 练习 00: 环境自检

## 目标

确认 Python 可以运行程序，确认当前目录是 Git 仓库，并观察基础标准库是否可用。

## 步骤

1. 运行 `python exercises/00-environment/check_environment.py`。
2. 检查输出中的 Python 版本、仓库状态和标准库检查。
3. 运行 `git status --short --branch`。
4. 如果全部通过，把结果写入 `docs/00-baseline.md`。

## 完成标准

- Python 可以成功执行脚本。
- 脚本退出状态为 0。
- Git 分支显示为 `main`。
