# 练习目录

练习按能力顺序排列。每个目录都应包含目标、操作步骤和完成标准。

- `00-environment/`: 检查 Python、Git 和仓库状态。
- `01-first-script/`: 编写并运行第一个 Python 程序。
- `02-variables-and-input/`: 完成变量、输入转换和函数练习。
- `03-conditions-and-loops/`: 分析一周学习记录并找出首次达标日期。
- `04-word-stats/`: 统计词频并生成文本摘要。
- `05-json-study-log/`: 把学习记录保存为 JSON 文件。

完成练习后，至少执行一次脚本或测试，并在周记录中写下结果。

运行仓库中的全部课程与练习检查:

```powershell
python tools/run_checks.py
```
