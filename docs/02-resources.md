# 资料索引

这些资料对应不同阶段。当前阶段只使用其中一项作为主线，其余作为补充。

## Python 基础

- CS50P: https://cs50.harvard.edu/python/
- Kaggle Learn Python: https://www.kaggle.com/learn/python

使用方式: 选择一门完成基础练习，同时把每章内容改写成自己的小脚本。

## 数据与自动化

- Kaggle Pandas: https://www.kaggle.com/learn/pandas
- Python 官方教程: https://docs.python.org/3/tutorial/
- pytest 文档: https://docs.pytest.org/

使用方式: 用公开数据或自己的日常任务练习，而不是只完成课程示例。

## 机器学习与深度学习

- CS50 AI: https://cs50.harvard.edu/ai/
- D2L: https://d2l.ai/
- fast.ai: https://course.fast.ai/
- DeepLearning.AI: https://www.deeplearning.ai/courses/

使用方式: 先完成一个端到端小项目，再补充理论。不要一开始逐章学完所有数学内容。

## AI 应用

- OpenAI API 文档: https://platform.openai.com/docs/
- 模型上下文协议: https://modelcontextprotocol.io/

使用方式: 从一个明确任务开始，例如“根据本地资料回答问题”，再逐步加入检索、评估和界面。

## 本地保存的页面

工作区中的 `*.html` 是资料快照，不应提交到 GitHub。需要引用内容时，优先记录原始官方链接和自己的理解。
